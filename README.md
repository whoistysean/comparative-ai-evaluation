Comparative AI Evaluation

About This Project

This is a beginner AI evaluation portfolio project demonstrating how to compare two AI-generated responses to the same question.

The project focuses on assessing response quality using five evaluation criteria.

Evaluation Criteria

* Accuracy
* Relevance
* Completeness
* Clarity
* Instruction Following

Project Exercise

Question: Explain the difference between weather and climate to a 12-year-old.

Two AI-generated responses were evaluated independently using a five-point scoring system.

Results

Criteria	        Response A	Response B
Accuracy	            5/5	       5/5
Relevance	            5/5	       5/5
Completeness	        5/5	       5/5
Clarity	              5/5	       5/5
Instruction Following	5/5	       5/5
Total	               25/25	    25/25

Final Evaluation

Both responses received equal scores. Response A was more direct and practical, while Response B used an analogy and examples to make the explanation engaging.

Both were considered suitable for the intended audience.
